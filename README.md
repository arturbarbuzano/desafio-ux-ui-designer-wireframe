# Desafio UX/UI Designer Wireframe

Olá, esse projeto foi desenvolvido como parte da trilha de UX/UI Designer da plataforma DIO no qual o desafio consistia em criar meu primeiro Wireframe de Média Fidelidade para uma única página de um produto qualquer, nesse caso foi escolido produtos voltados para o tênis de mesa. 

Foi utilizado a plataforma Figma para prototipação da página e foi aplicado conceitos de psicologia do design e usabilidade aprendidos no curso, em um cenário real de criação de interfaces. Veja a seguir como ficou o projeto:
